## 📌 About the Project

The **Cold Chain Monitoring System** is a web-based dashboard designed to monitor and manage cold-chain operations in one place.

Cold-chain management is important for transporting and storing temperature-sensitive products such as medicines, vaccines, food, and other perishable goods.

This project provides a centralized dashboard where users can view temperature readings, shipment information, alerts, and vehicle details through a simple and user-friendly interface.

The main objective is to demonstrate how a digital monitoring dashboard can help improve visibility, organization, and management of cold-chain operations.

> **Note:** This is a frontend demonstration project that uses simulated data. It is not connected to real IoT sensors, GPS devices, or live tracking services.

---

## ✨ Features

### 1. Dashboard Overview
- Displays important operational statistics.
- Provides an overview of shipments and temperature conditions.
- Shows recent shipment information.
- Displays summary cards and visual charts.

### 2. Temperature Monitoring
- Displays temperature readings.
- Provides a temperature trend chart.
- Helps visualize temperature variations over time.
- Makes it easier to identify unusual temperature conditions in the demo data.

### 3. Shipment Management
- Displays shipment information in a structured table.
- Provides shipment-related details.
- Includes filtering options for viewing shipment records.

### 4. Alert Management
- Displays cold-chain alerts.
- Helps users identify temperature-related issues.
- Organizes alerts for easier monitoring.

### 5. Vehicle Management
- Displays vehicle-related information.
- Provides an overview of vehicles used in transportation.

### 6. User Profile
- Provides an Update Profile dialog.
- Allows users to update their name and email address.
- Uses browser localStorage to retain profile information.

### 7. Login Page
- Includes a separate login interface.
- Provides a basic frontend demonstration of login functionality.

## 🚀 How to Run the Project

Follow these steps to run the project on your computer.

### Prerequisites

- A computer with Windows, macOS, or Linux.
- Visual Studio Code (recommended).
- A modern web browser such as Google Chrome.
- Live Server extension in VS Code.

### Installation Steps

**Step 1: Download or Clone the Repository**

```bash
git clone https://github.com/the-himant/cold-chain-monitoring-system.git
```

Alternatively, download the ZIP file and extract it.

**Step 2: Open the Project**

Open the `cold_chain_dashboard1` folder in Visual Studio Code.

**Step 3: Install Live Server**

1. Open VS Code.
2. Go to Extensions.
3. Search for Live Server.
4. Install the extension.

**Step 4: Run the Project**

1. Open the `login` folder.
2. Right-click on `login.html`.
3. Select **Open with Live Server**.
4. The login page will open in your browser.

## 🔐 Important Information

This project is developed for educational and demonstration purposes.

- Login functionality is frontend-based and is not a secure authentication system.
- Profile information is stored locally in the browser.
- Dashboard readings and shipment records are simulated.
- No real-time IoT sensor integration or GPS tracking is implemented.
- The project does not currently use a backend database.
